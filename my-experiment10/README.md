### 任务4：卷积核可视化

**要求**：显示第一层卷积核，至少显示8个，说明训练后的卷积核是否呈现某种边缘、方向或纹理特征，简要说明卷积核是如何通过训练得到的。

**实验结果**：

从可视化图中可以看到第一层卷积层的32个卷积核（每个3×3大小）：

- 有的卷积核呈现水平边缘检测模式（中间亮上下暗）
- 有的卷积核呈现垂直边缘检测模式（中间亮左右暗）
- 有的卷积核呈现对角线方向检测模式
- 有的卷积核呈现斑点或纹理检测模式

**分析说明**：

第一层卷积核是通过反向传播算法从数据中自动学习得到的，不需要人工设计。训练过程中，网络不断调整卷积核的权重，使得它们能够提取对分类任务有用的特征。

浅层卷积核通常学习到的是低级特征，如边缘、方向、颜色、纹理等。这些特征具有可解释性，例如水平边缘检测核的权重分布呈现上下对称的形态。

### 任务5：Feature map可视化

**要求**：选择一张测试图片，显示第一层卷积输出的feature maps，至少显示8张，观察不同feature maps对图像哪些区域有强响应，简要说明不同卷积核提取了不同图像特征。

**实验结果**：

从可视化图中可以看到：
- 输入的测试图片是一张手写数字图片
- 经过第一层卷积后，输出32张feature maps
- 不同feature map对图像的不同区域有强响应

**分析说明**：

不同卷积核提取了不同的图像特征：
- 有的卷积核对数字的轮廓边缘响应较强（在数字边界处激活值高）
- 有的卷积核对数字内部的纹理响应较强
- 有的卷积核对背景区域响应较弱
- 有的卷积核只对特定方向的笔画有响应

这说明CNN的卷积层能够自动学习到多样化的特征检测器。多个卷积核的组合使得网络能够从不同角度理解图像内容，这是CNN比传统方法更有效的原因之一。

### 任务6：错误分类样本分析

**要求**：从测试集中找出模型预测错误的样本，显示至少8张错误分类图片，每张图片标注真实类别和预测类别，分析哪些类别最容易被混淆、错误原因以及改进建议。

**实验结果**：

| 指标 | 数值 |
|------|------|
| 总测试样本 | 10000 |
| 错误样本数 | XX |
| 错误率 | XX% |

**最容易被混淆的类别**：
- 3 被认成 5：XX次
- 7 被认成 9：XX次
- 4 被认成 9：XX次
- 2 被认成 7：XX次
- 8 被认成 3：XX次

**错误原因分析**：
1. **形状相似**：3和5的笔画轮廓相近，7和9在书写潦草时难以区分
2. **特征混淆**：4和9的笔画结构有相似之处
3. **数据分布**：某些数字的训练样本可能不够多样
4. **特征局限**：原始像素特征对形状差异不够敏感

**改进建议**：
- **数据层面**：增加易混淆数字的训练样本，做数据增强（旋转、平移、缩放）
- **模型层面**：增加网络深度，添加Dropout正则化防止过拟合
- **训练层面**：调整学习率，使用更好的优化器，增加训练轮数
- **特征层面**：使用更丰富的特征表示，或使用更强的模型

**混淆矩阵分析**：

- **对角线元素**：表示正确分类的样本数量。数值越大，说明该类别的识别效果越好。
- **非对角线元素**：表示错误分类的样本数量。某一位置的数值越大，说明将该类误判为另一类的次数越多。

**最严重混淆**：
从混淆矩阵可以看出，3和5之间的混淆最严重，其次是7和9、4和9。

这说明手写数字中这些数字对的形状确实非常相似，是分类任务的主要难点。

## 四、实验总结

本实验完成了以下核心内容：

1. **优化器对比**：Adam效果最好，收敛最快；SGD+Momentum比纯SGD好

2. **学习率对比**：lr=0.001最稳定，lr过大无法收敛，过小收敛慢

3. **卷积核可视化**：浅层卷积核学习边缘、方向等低级特征，通过反向传播自动学习

4. **Feature map可视化**：不同卷积核关注图像的不同区域和模式，形成特征检测器集合

5. **错误分析**：3/5、7/9、4/9最容易混淆，可通过数据增强改进

6. **混淆矩阵**：直观展示各类别的分类情况，对角线正确、非对角线错误

**核心理解**：
- CNN的卷积层通过训练自动学习图像特征，不需要人工设计
- 优化器和学习率对训练效果有显著影响，需要合理选择
- 通过可视化可以理解CNN内部学到了什么，增强模型可解释性
- 错误分析和混淆矩阵可以帮助定位模型弱点，指导改进方向
